# Astar Vanguard / 星锋战术支援

[English](README.md) · **简体中文**

面向 **SPT 4.0.13 / EFT 40087** 的 AI 战术支援 Mod。

希望把 AI 队友做成真正可以长期使用和管理的一支固定队伍，而不是每次进入战局都重新生成一批没有身份感的临时 Bot。当前版本围绕星锋指挥中心、固定干员体系与战术支援玩法持续重构，并会沿独立路线继续开发。

## 当前内容

- 加入 **星锋指挥部** 与独立的指挥中心界面。
- 提供 **37 名固定干员**，每名干员都有自己的代号、定位与战斗能力。
- 支持永久招募，并保留已经加入名册的干员身份。
- 支持 **1–4 人出击编队**，可在指挥中心中直接管理准备带入战局的干员。
- 为不同干员配置独立的瞄准、视野、听觉、反应、进攻倾向、伤害、敌人记忆与掩体能力。
- 继续保留并维护战术 AI 队友相关的指令、交互与 Fika 联机能力。

## 当前支持环境

目前只针对下面这套环境开发和验证：

- **SPT 4.0.13**
- **EFT Build 40087**
- **BigBrain**
- **Fika Host / Solo Host**

其他 SPT / EFT 版本不默认视为兼容。Fika 目前主要按 Host / Solo Host 场景维护；远端 Client 的完整行为会随着后续版本继续验证和收敛。

## 安装与使用

可直接安装的版本会放在 GitHub Releases。发布包完成后，按压缩包中的目录结构覆盖到对应的 SPT 安装目录即可；不要把 GitHub 自动生成的 `Source code` 压缩包当作 Mod 安装包。

主要入口位于商人界面的 **星锋指挥部**。进入指挥中心后，可以查看干员名册、永久招募干员，并调整当前出击编队。

客户端依赖 BigBrain；使用 Fika 联机功能时，还需要安装与当前环境匹配的 Fika。正式发布包会一并处理所需的 UI 运行组件，不需要额外寻找开发源码。

## 源码

源码会在这个仓库持续维护。当前明确以 SPT 4.0.13 / EFT 40087 为目标；如需自行构建，需要准备与这套环境匹配的本地开发依赖。

```powershell
dotnet build .\Astar.Vanguard.slnx -c Debug
dotnet build .\Astar.Vanguard.slnx -c Release
```
